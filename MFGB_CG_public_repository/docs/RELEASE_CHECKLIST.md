# Computers & Geosciences repository checklist

- [ ] GitHub visibility is **Public**.
- [ ] The URL opens in a signed-out/private browser window.
- [ ] Source files appear individually; no source-code ZIP is stored in GitHub.
- [ ] `README.md` renders correctly on the repository front page.
- [ ] A clean environment can install `requirements.txt`.
- [ ] `python examples/quick_test.py` prints `QUICK TEST PASSED`.
- [ ] `python -m unittest discover -s tests -v` passes.
- [ ] No local absolute paths, credentials, private data, or cache files remain.
- [ ] Study-specific parameters match the submitted manuscript.
- [ ] Redistributable benchmark inputs and reproduction scripts are included or linked.
- [ ] The manuscript ends with the section **Computer Code Availability**.
- [ ] The manuscript repository URL is `https://github.com/ddlulu/MFGB`.
- [ ] The manuscript main text is within the journal's 5,500-word limit.
