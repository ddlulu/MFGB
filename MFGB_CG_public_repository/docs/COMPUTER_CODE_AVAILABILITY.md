# Computer Code Availability

The source code implementing the Multi-Factor Game-Based (MFGB) flow-routing
algorithm, together with dependency information, documentation, automated
tests, and a quick-test example, is openly available from the following public
GitHub repository:

https://github.com/ddlulu/MFGB

The repository can be accessed and downloaded anonymously. The released code
is written in Python 3 and is distributed under the MIT License.
